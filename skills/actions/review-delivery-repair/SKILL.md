# 独立定向修复审核

实际独立 Reviewer 固定当前完整且完成的新 Author，读取其直接正式失败、范围、原整个集合、实际差异及定向验证。actor 与 Author 不同是明显冲突检查，不能认证真人独立性；自动化 approved 只能是记录夹具，不能批准真实仓库 Change。

核对修复与执行配置变化仍在已批准范围内、完整集合未被缩减、材料说明可靠。说明当前受测材料适用性与限制，不因脚本文字合理变化机械重做 Explore / Propose，不生成 hash gate。缺必要对象停止对应审核操作；本地 draft 可保存故障说明，普通查询只解释当前头部。

complete 给 approved / changes-requested / rejected：分别转新的整次正式执行、新 Author 修订或 Owner 决策。continuing 后继续仍固定同一 Author。Reviewer 不修改实现后自签批准；工具成功、focused 和正文齐全不代替语义审核或正式 Full Test，不自动 Close。
